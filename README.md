# Fashion

Fashion is a collection of frontend libraries for designing and laying out web
pages. It includes React components, sizing utilities, color and theme builders,
and a default dark theme.

## Packages

| Package                                                            | Description                                                               |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| [@zthun/fashion-boutique](packages/fashion-boutique/README.md)     | React UI components and hooks for themes, sizing, and responsive layouts. |
| [@zthun/fashion-tailor](packages/fashion-tailor/README.md)         | Size charts, spacing utilities, and responsive breakpoints.               |
| [@zthun/fashion-theme](packages/fashion-theme/README.md)           | Color utilities and builders for component color states and themes.       |
| [@zthun/fashion-theme-dark](packages/fashion-theme-dark/README.md) | The default dark theme for the Fashion system.                            |
| [@zthun/fashion-web](packages/fashion-web/README.md)               | A demo website for the components and themes.                             |
