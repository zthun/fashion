# @zthun/fashion-web

A React demo website for the Fashion system. It showcases components from
`@zthun/fashion-boutique` and color schemes from `@zthun/fashion-theme`, using
`@zthun/fashion-theme-dark` as the application theme.

The site includes interactive examples of form controls, layout components,
dialogs, navigation, typography, loading indicators, and embedded YouTube
videos.
